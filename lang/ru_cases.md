ロシア語の格は 6つ あるよ！

| 日本語    | ロシア語         | 主な意味・用法     |
| ------ | ------------ | ----------- |
| 主格     | Именительный | 〜は、〜が       |
| 生格（属格） | Родительный  | 〜の、〜から、〜がない |
| 与格     | Дательный    | 〜に、〜へ       |
| 対格     | Винительный  | 〜を、〜へ       |
| 造格（具格） | Творительный | 〜で、〜によって、〜と |
| 前置格    | Предложный   | 前置詞とともに使う   |


特に覚えておきたいのは次の2つ。

* 対格：直接目的語を表す。Я читаю книгу.（私は本を読む）

* 造格：手段や道具、同伴などを表す。Я пишу ручкой.（私はペンで書く）
